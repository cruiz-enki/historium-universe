# HISTORIUM — E001 // OPERADOR LIA

**Arco:** Historium Origins  
**Episodio:** E001  
**Título de trabajo:** Expediente 0001 // Operador Lia  
**Estado:** preproducción  
**Formato maestro:** video narrativo cinematográfico 3–5 min  
**Coordenada histórica principal:** Pompeya, 63 a.C.

## Objetivo

Producir el primer episodio narrativo canónico del Historium Universe y documentar cada fase para que el proceso pueda repetirse y escalar.

## Pipeline del episodio

1. `01_Research.md` — investigación y guardrails históricos.
2. `02_Guion_Maestro.md` — historia audiovisual y diálogos.
3. `03_Guion_Voz.md` — texto final por personaje y timecodes.
4. `04_Shot_List.md` — escenas, planos, duración y técnica.
5. `05_Visual_Bible.md` — Lia, Kronos, dispositivo, Pompeya, Tertia, escenarios.
6. `06_Image_Prompts.md` — prompts de imágenes maestras y keyframes.
7. `07_Video_Prompts.md` — prompts de animación / image-to-video / text-to-video.
8. `08_Audio_Sound_Design.md` — voces, ambientes, SFX y música.
9. `09_Edit_Plan.md` — montaje, interfaces Historium, ritmo y master.
10. `10_Derivatives.md` — Shorts, Reels, TikToks, carruseles y teasers derivados.
11. `11_Postmortem.md` — métricas y aprendizaje para retroalimentar el pipeline.
